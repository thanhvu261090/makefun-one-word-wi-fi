One word describing my Wi-Fi:

> "Ghosting"

My Wi-Fi is there one second and gone the next — exactly when I need it most, like a date that never texts back.

## How it works

`main.py` holds the entry word as a constant, checks it against the kit's gate (UTF-8 text, 1–20 characters, not only whitespace, a single alphabetic word with no whitespace, padding, or control characters), and writes it to `/output/entry.txt` when run with `python3 main.py`.
